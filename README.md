# Md Arafat Hossain — IT Support Portfolio

A static, GitHub Pages-ready portfolio website built from the authoritative IT Support CV.

## Files

- `index.html` — portfolio content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `cv/Md_Arafat_Hossain_Europass_IT_Support_CV_Original.pdf` — downloadable CV

## Publish with GitHub Pages

1. Create a GitHub repository named exactly `<your-username>.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, the `cv` folder, and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Open `https://<your-username>.github.io` after GitHub finishes publishing.

No build tool or paid hosting is required. To update the site later, edit the files and commit the changes to the same repository.

## Before publishing

- Replace the professional-links note in `index.html` with your exact LinkedIn/GitHub URLs when available.
- Review the public contact details and downloadable CV.
- Keep the CV filename and the download link aligned if you rename the PDF.
